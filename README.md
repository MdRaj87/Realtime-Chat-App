💬 Full-Stack Real-Time Chat Application

This project demonstrates how to build and deploy a production-ready chat application from scratch using the MERN stack. It includes custom authentication, real-time communication, and modern deployment strategies.

🌟 Features:
✔️ Secure JWT-based Authentication (No 3rd-party)
✔️ Real-time 1-on-1 messaging with Socket.io
✔️ Live online/offline presence indicators
✔️ Typing & notification sounds
✔️ Welcome emails on signup (Resend)
✔️ Image uploads (Cloudinary)
✔️ API Rate-Limiting (Arcjet)
✔️ Clean UI with React, Tailwind CSS, and DaisyUI
✔️ State Management with Zustand
✔️ Git & GitHub Workflow best practices
